# Brief

## 1. Purpose
A walking tour of Deck Arsenal 2: what problem it solves, how a brief
becomes a finished deck through five gated stages, and where DA2 differs
from its predecessor.

## 2. Single takeaway
DA2 is the same workflow as DA1 with the rendering engine swapped to
open-slide — gaining React expressiveness, a click-to-comment inspector,
and a universal-memo concept that feeds non-deck artifacts.

## 3. Anything the agent should know
This deck is internal documentation. Tone should be sharp and concrete,
not promotional. Reference the previous DA1 dryrun deck for shape —
DA2's version of this should feel like a sibling, not a sequel that
trashes its predecessor.
