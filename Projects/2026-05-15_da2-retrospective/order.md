# Brief

## 1. Purpose
Walk a fresh reader through what got built across the six DA2 phases:
what the substrate is, how the workflow stayed intact, what changed
about editing, and what landed where in the directory.

## 2. Single takeaway
The workflow survived an engine swap. open-slide replaced the HTML
stitcher; everything upstream (order → memo → storyboard) and around
(approval gates, project folder shape, derived artifacts) is the same
shape with a new substrate, and the Taikyoku theme proves the substrate
can carry brand-shaped aesthetics.

## 3. Anything the agent should know
This is the reference deck for the Taikyoku theme + executive-pitch
recipe. Use it to validate that the recipe's six beats compose cleanly
end-to-end with Taikyoku's restrained register. Keep the content
honest — call out what we deferred (kanji seal, video backgrounds,
nested slides) so the deck doesn't oversell.
